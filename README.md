# Personal Website

A lightweight astronomy-themed personal academic website for GitHub Pages.

## Files

- `index.html`: page structure and editable text
- `styles.css`: responsive layout, portrait panel, and astronomy-themed visual style
- `script.js`: theme toggle, current year, and animated sky background
- `assets/profile-placeholder.svg`: temporary portrait placeholder

## Add Your Photo

1. Put your personal photo in `assets/`.
2. Rename it to `profile.jpg`.
3. Refresh the page. If `profile.jpg` is missing, the site will show the placeholder automatically.

Square or vertical photos work best. The page crops the image to a 4:5 portrait frame.

## Update the Website

After editing files locally:

```powershell
git add .
git commit -m "Update personal website"
git push
```

GitHub Pages should update after a short delay.
